# AquaMind

Modern, mobil öncelikli akvaryum yönetim uygulaması MVP'si.

## Yol haritası

- Akvaryum yönetimi
- Su değerleri ve grafikler
- Bakım günlüğü ve tekrarlayan görevler
- Canlılar, bitkiler ve ekipmanlar
- Hacim, su değişimi ve kum litre hesaplayıcıları (kum türü seçimiyle)

## Çalıştırma

```bash
pnpm install
pnpm dev
```

Ardından `http://localhost:3000` adresini açın.

## Kontroller

```bash
pnpm typecheck
pnpm build
pnpm verify
```

## Ortak geliştirme

Projede çalışmadan önce `AGENTS.md`, `PROJECT_STATUS.md` ve `CONTRIBUTING.md` dosyalarını okuyun. Claude Code ayrıca `CLAUDE.md` talimatlarını izler.
